把 Flow2API 配成 Magpie 供应商

  1. 打开 Magpie → 供应商 → 添加供应商，搜索 Flow2API，选择「添加为自定义供应商」。
  2. 名称填 Flow2API，协议选 OpenAI 兼容。
  3. Base URL 填 ；调用密钥使用系统配置里的「调用密钥」。
  4. 点击「获取模型」，先保留 gemini-3.1-flash-lite-image-square 和 gemini-3.1-flash-image-square，便于先验证图片流程。
  5. 添加后，从 Magpie 网关模型列表确认实际前缀，再在支持 Chat Completions 的工具中使用完整模型 ID。
先用图片模型确认能出图。返回的是图片链接或视频标签，不能当成聊天或编程助手。
Flow2API 的视频走 /v1/chat/completions。Magpie 内置 Grok 视频走 /v1/videos。这两个地址不能互换。
经 Magpie 查看模型
Magpie 默认网关示例为本机 127.0.0.1:3425。密钥从 Magpie 网关页取得。不同机器上，127.0.0.1 指向各自本机；远程工具需要能访问这台 Mac 的地址。


怎样算生成成功
stream: false 从 choices[0].message.content 取结果；stream: true 按 SSE 读取 choices[].delta，直到 data: [DONE]。
图片：![Generated Image](https://…)
视频：<video src='https://…' data-media-id='…' controls></video>
有图片 / 视频结果才算成功。流式请求可能 HTTP 200 后仍返回 error；客户端必须检测错误事件，不能只判断状态码。下载后再检查文件类型、尺寸与内容。成功结果已自动保存到服务所在电脑的 data/generated/，可在「本机资源」查看和下载。永久资源独立于临时缓存；仅清理 tmp 不会删除作品。/media/文件名 是持有链接即可访问的资源地址，便于 Magpie 等客户端取图，请勿公开分享私密作品链接。
工作台会把过程日志与作品分开展示。生成中断时先查管理控制台的请求日志，再决定是否重试，避免重复创建任务。


遇到问题时
没有可用的账号
到 Google 账号页看它是不是可用、登录是否过期。不要反复提交同一次生成。
ego 工作区由用户控制 / trusted 初始化失败
把绑定的工作区控制权交还 Agent，并保持标签页打开。项目切换后必须重新初始化验证码；当前桥接器会在导航前注册脚本、导航后检查状态。关闭工作区后需要重新配置绑定。
模型在列表里，为什么还是权限不足？
模型目录描述接口能力；Google 账号的订阅、地区、额度决定是否能实际使用。Veo 各规格需单独确认权限。不要从图片成功推断视频一定成功。
Magpie 中的模型看得到，但工具不能出图
先用文档中的直连接口验证，再经 Magpie 用相同提示词验证。工具必须调用 Chat Completions 并能处理媒体链接。仅拉取模型列表成功，不代表生成链路已调通。
调用密钥和管理员登录有什么区别？
管理员登录用来打开这个网页。调用密钥用来让程序生成图片或视频。网页工作台会使用已经保存的调用密钥。外部工具仍要自己填写。不要把 Google Cookie 当作调用密钥。
