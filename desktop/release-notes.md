## 0.2.1

- Google 账号支持一键弹窗登录与 Chrome 扩展 / 油猴脚本双模式同步导入。
- 点击「登录 Google 账号」自动调起独立 Chrome 窗口直达登录，无需手动填邮箱与选择资料目录。
- 桌面端内置 Chrome 扩展与油猴脚本分发接口，支持一键以插件模式打开 Chrome 或一键安装油猴脚本。
- 新增 `POST /api/browser-login/sync` 接口与 CORS 预检支持，在日常浏览器登录 Flow 后一键同步到桌面端。

## 0.2.0

- 登录后自动启动读取系统开机项。手动打开显示窗口，自启只留在托盘或菜单栏。
- 设置页可以手动测试、上传和下载 WebDAV 配置，支持从 Clash Verge 导入；应用密码留在系统凭据库。
- 保存运行设置、下载合并 WebDAV 或导入旧版数据时，若无执行中任务会自动平滑重启 API 立即生效。
- Google 账号支持“添加并打开登录”，在 Chrome 完成登录后自动检测并同步余额与就绪状态。
- 本机作品归档保存提示词与模型，支持一键填入工作台与视频一键续写；任务、作品、账号和旧版历史列表统一支持关键字/维度筛选、分页、正逆序切换与本机状态记忆。
- 私有 GitHub Release 提供 macOS 通用包和 Windows x64 当前用户安装包，应用内更新会验签。
