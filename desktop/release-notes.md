# v0.3.9 · 界面精简、响应式布局与无障碍体验升级

- **更简洁的界面结构**：
  - 顶部状态摘要仅在「创作工作台」与「任务与进度」显示，作品库、账号页与设置页直达核心内容。
  - 顶部栏仅在检测到新版本时展示升级提醒按钮，减少重复入口干扰。
  - 精简账号页首屏操作（将备用连接码收入高级折叠区），WebDAV 配置与同步操作清晰分组，折叠菜单补充展开箭头提示，设置分区导航增加横向滑动渐变提示。
  - 合并清理多层重复 CSS，全面采用逻辑属性，弹窗固定底部操作栏并仅滚动主体内容。
- **全面无障碍（WCAG 2.2）修复**：
  - 窄屏与高缩放（320px / 200%+）保留侧栏状态与「退出应用」入口，表单网格与状态卡自动折为单列不裁剪。
  - 修复吸顶导航与底部提交栏遮挡焦点元素的问题（`scroll-margin-block-start` / `scroll-padding-block-end`）。
  - 按钮执行中与不可用态改用 `aria-disabled="true"` 保留键盘焦点，避免操作后焦点丢失回页面顶部。
  - 引入常驻实时区域播报状态与错误通知，支持悬停／聚焦暂停自动关闭；为视频预览、列表计数、表单错误 `aria-describedby` 与连接脚本悬浮窗补齐无障碍语义；扩大细小按钮点击命中区至 28px+。

# v0.3.8 · 自动后台更新增强与数据库/轮询性能优化

- **自动后台更新全面增强**：
  - 支持后台静默检查（启动 15 秒后及每 2 小时）、后台预下载并持久化已验签更新包至磁盘缓存，即使当前有生成任务也能提前完成下载与签名校验，任务空闲后立即安装重启，不再丢弃下载重来。
  - 修复更新重启时与单实例锁、`instance.lock` 文件锁竞态导致重启失败的问题；跨平台在退出前释放锁并在启动时做短时重试。
  - 窗口隐藏在菜单栏／托盘时触发的自动更新在重启后保持静默常驻，不再突然弹窗打扰。
  - 更新器遵循设置中的 HTTP/SOCKS5 代理配置，增加超时分段与瞬时网络重试，提升国内及弱网环境稳定性。
  - 自动更新开关支持即时生效且不再重启本机 API 或关闭浏览器；菜单栏／托盘菜单同步显示后台更新状态并提供「自动后台更新」开关。
- **性能大幅优化**：
  - 数据库升级至 Schema v3：将任务中的 base64 参考图抽离至内容寻址去重的 `task_assets` 表，大幅降低 `desktop.db` 体积与启动内存占用，首次启动自动无损迁移并回收空间。
  - 状态刷新改用 SQLite 聚合统计；默认浏览器 500ms 轮询仅在状态变化时触发刷新；窗口隐藏时暂停前端定时轮询，显著降低后台空闲 CPU 与磁盘 I/O。
  - 缓存 Flow RPC 正则解析器；修改非端口／非浏览器设置不再无谓重启 API 服务或断开浏览器会话。

# v0.3.4 · 账号调度管理、失败原因诊断与本机免连接码直连

- Google 账号管理增强：新增账号优先级（首选主力／高优先／普通／低优先／仅作备用）、临时禁用冷却（15 分钟／1 小时／6 小时／24 小时自动恢复）、允许生图／允许生视频能力分流开关、账号备注、全部账号一键同步余额及最近错误统计。
- 多账号智能分配：自动选择空闲账号时，按「当前空闲 → 优先级 → 近期连续失败次数 → 最近使用时间 → 积分余额」排序，并按任务类型自动过滤已关闭图片或视频开关的账号。
- 失败原因详细可读化：将 `PUBLIC_ERROR_MODEL_ACCESS_DENIED`、`PUBLIC_ERROR_UNSAFE_GENERATION`、`PUBLIC_ERROR_PROMINENT_PEOPLE_FILTER_FAILED`、`PUBLIC_ERROR_QUOTA_EXCEEDED` 及 `Flow RPC 返回错误或缺少数据`（含 gRPC 状态码）转换为清晰的中文阶段说明、原因诊断与恢复建议，并在任务卡片提供「换其他账号重试」与「临时禁用该号 1h」快捷操作。
- 视频模型通道自动回退：当账号不支持 `*_relaxed` 慢速免积分通道时自动回退至标准模型键重试。
- 本机浏览器免连接码直连：`127.0.0.1` / `localhost` 支持免填连接码一键或自动配对连接，连接脚本（v2.1.0）支持打开 Flow 页面后自动连接及悬浮窗折叠收起。
- 界面与交互体验优化：错误横幅支持手动关闭，弹窗关闭自动恢复焦点，账号与任务列表支持按优先级、冷却状态及中文错误诊断检索筛选。
