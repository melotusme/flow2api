# v0.4.1 · 移除无登录态独立 Chrome 弹窗、Chrome 多配置一键拖拽装插件与已开标签页即刻同步

- **彻底移除独立无登录态 Chrome 调试窗口**：
  - 所有账号（含旧版数据库记录与 WebDAV 云端合并账号）统一迁移为默认浏览器直连模式（`browser_bridge = true`），启动时自动清理遗留的独立 `profiles/` 目录，点击「同步」或执行任务时绝不再拉起无登录态的受控调试 Chrome（彻底解决 Google 拦截自动化浏览器登录的问题）。
  - 智能同步体验：对尚未连接标签页的账号点击「同步」或「打开 Flow ↗」时，自动按邮箱匹配本机对应的真实 Chrome 用户配置（如 AI Ultra 所在的 `Profile`）打开页面并等待自动回连校验。
- **Chrome 多配置自动识别与一键拖拽安装插件**：
  - 账号页新增「本机 Chrome 配置与插件状态」面板，只读识别系统 Chrome 各配置的 Google 账号、扩展安装状态与版本号（不读取任何 Cookie）。
  - 点击「一键安装插件」自动在对应 Chrome 配置打开 `chrome://extensions/`，同时在系统文件管理器中高亮选中 `chrome-extension` 文件夹并复制路径，直接将高亮文件夹拖入扩展页即可完成安装。
- **已打开标签页免刷新即刻接管与权限零配置**：
  - Chrome 扩展（`v0.4.1`）在安装、升级或浏览器启动时自动向已打开的 `flow.google.com` 与 `flowmusic.app` 标签页注入桥接脚本，无需手动刷新页面即可在 1 秒内完成配对与余额同步；全部站点与本机通信权限随扩展加载自动生效，无需开启 Tampermonkey「允许运行用户脚本」或确认跨域弹窗。
  - 新增 `flowmusic.app` 分片及 `HttpOnly` 认证令牌的浏览器内回退识别，令牌始终不离开浏览器。

# v0.3.8 · 自动后台更新增强与数据库/轮询性能优化

  - 支持后台静默检查（启动 15 秒后及每 2 小时）、后台预下载并持久化已验签更新包至磁盘缓存，即使当前有生成任务也能提前完成下载与签名校验，任务空闲后立即安装重启，不再丢弃下载重来。

  - 窗口隐藏在菜单栏／托盘时触发的自动更新在重启后保持静默常驻，不再突然弹窗打扰。
  - 更新器遵循设置中的 HTTP/SOCKS5 代理配置，增加超时分段与瞬时网络重试，提升国内及弱网环境稳定性。
  - 自动更新开关支持即时生效且不再重启本机 API 或关闭浏览器；菜单栏／托盘菜单同步显示后台更新状态并提供「自动后台更新」开关。
- **性能大幅优化**：
  - 数据库升级至 Schema v3：将任务中的 base64 参考图抽离至内容寻址去重的 `task_assets` 表，大幅降低 `desktop.db` 体积与启动内存占用，首次启动自动无损迁移并回收空间。
  - 状态刷新改用 SQLite 聚合统计；默认浏览器 500ms 轮询仅在状态变化时触发刷新；窗口隐藏时暂停前端定时轮询，显著降低后台空闲 CPU 与磁盘 I/O。
  - 缓存 Flow RPC 正则解析器；修改非端口／非浏览器设置不再无谓重启 API 服务或断开浏览器会话。
