# v0.3.5 · 菜单栏常驻

- 关闭主窗口后，macOS 只留在菜单栏（图标和文字 Flow），Windows 留在通知区域。API 继续运行，Dock 和任务栏按钮不再占位。
- 菜单「打开 Flow2API」、再次启动，或在 macOS 重新打开应用，会回到主窗口。
- 只有「退出 Flow2API」停止进程。有未完成任务时仍拒绝退出。
- 登录后自动启动只留在菜单栏，不弹出窗口。
- 源码仓库只保留桌面应用，不再包含旧的 Python 服务、网页和 Docker。

# v0.3.4 · 账号调度管理、失败原因诊断与本机免连接码直连

- Google 账号管理增强：新增账号优先级（首选主力／高优先／普通／低优先／仅作备用）、临时禁用冷却（15 分钟／1 小时／6 小时／24 小时自动恢复）、允许生图／允许生视频能力分流开关、账号备注、全部账号一键同步余额及最近错误统计。
- 多账号智能分配：自动选择空闲账号时，按「当前空闲 → 优先级 → 近期连续失败次数 → 最近使用时间 → 积分余额」排序，并按任务类型自动过滤已关闭图片或视频开关的账号。
- 失败原因详细可读化：将 `PUBLIC_ERROR_MODEL_ACCESS_DENIED`、`PUBLIC_ERROR_UNSAFE_GENERATION`、`PUBLIC_ERROR_PROMINENT_PEOPLE_FILTER_FAILED`、`PUBLIC_ERROR_QUOTA_EXCEEDED` 及 `Flow RPC 返回错误或缺少数据`（含 gRPC 状态码）转换为清晰的中文阶段说明、原因诊断与恢复建议，并在任务卡片提供「换其他账号重试」与「临时禁用该号 1h」快捷操作。
- 视频模型通道自动回退：当账号不支持 `*_relaxed` 慢速免积分通道时自动回退至标准模型键重试。
- 本机浏览器免连接码直连：`127.0.0.1` / `localhost` 支持免填连接码一键或自动配对连接，连接脚本（v2.1.0）支持打开 Flow 页面后自动连接及悬浮窗折叠收起。
- 界面与交互体验优化：错误横幅支持手动关闭，弹窗关闭自动恢复焦点，账号与任务列表支持按优先级、冷却状态及中文错误诊断检索筛选。

# v0.3.3 · 公开发布与异步任务接口

- 发行仓库改为公开：检查和下载更新不再需要 GitHub CLI 或 GitHub Desktop 登录，仍在安装前校验签名和版本。下载地址限定在发行仓库，跳转只允许到 GitHub 发布 CDN。
- 新增 `/v1/tasks` 异步任务接口：提交后立即返回任务 ID，可查询进度和取消。
- 视频续写自动匹配生成原视频的账号。
- 常用账号快捷按钮改为读取本机 `local.env` 或环境变量 `FLOW2API_PREFERRED_EMAILS`，源码不再包含个人邮箱。

# v0.3.2 · 复用 GitHub Desktop 登录

- 私有更新新增 macOS 钥匙串、Windows 凭据管理器的 GitHub Desktop 登录复用；CLI 不可用、登录失效或无仓库权限时自动尝试 Desktop。
- 每次检查和下载都验证固定私有发行仓库的实际读取权限，设置页显示认证来源。
- 只读系统中 Desktop 拥有的 GitHub.com 凭据，兼容普通及版本化 OAuth 存储；不复制持久化令牌、不使用或轮换刷新令牌、不修改 Desktop 登录。
- 后台检查不弹凭据授权窗口；macOS 首次需要时可在手动检查中授权读取。Linux 保留 CLI 更新路径。

# v0.3.1 · 主分支统一与自动更新

- 合并现有桌面分支、上游 main/beta 和 PR 功能至主分支。
- 创作工作台支持模型规格、参考图、流式进度、任务与作品归档；一键接入 Magpie，Agent 通过 hzr-flow2api-image 生图。
- 默认浏览器连接支持 Ego Lite / Chrome，保留专用 Chrome 高级选项；保留上游 Cookie 刷新、团队打码、多语言和高级模型测试入口。
- 默认启动 30 秒后、之后每 6 小时自动检查私有更新，关闭窗口后仍运行。任务空闲后下载、验签、安装并重启；检查失败 30 分钟后重试，安装失败恢复 API。
- 设置页可关闭本机自动更新，并显示最后检查时间和错误。各设备需要已登录的 GitHub CLI 及私有发行仓库读取权限。
- 修复私有 GitHub 资产重定向；凭据只发往固定仓库 API，CDN 下载不携带令牌。更新签名绑定版本号。
- 正式发行包含 macOS Apple Silicon / Intel 通用包与 Windows x64 安装器、Linux x64 AppImage。Google 登录、数据和设置保留在各电脑本机。
