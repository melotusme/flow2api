连接 Google 账号

支持两种方式：① 点击一键打开 Chrome 登录（无需配置）；② 通过 Chrome 扩展或油猴脚本从日常浏览器一键同步导入。

双模式支持

方式 ①：点击「登录 Google 账号」，应用打开独立窗口，登录后自动建档同步。
方式 ②：在日常 Chrome 中使用扩展或油猴脚本，登录 flow.google.com 后点击「同步到 Flow2API」，即可直接把登录态导入本应用。

高级选项：按邮箱添加或手动安装扩展

若需在日常 Chrome 中永久安装扩展：在 Chrome 打开 chrome://extensions 并开启右上角「开发者模式」，点击上方「打开扩展目录」，将打开的 extension 文件夹拖入 Chrome 即可完成安装。

后台运行

关闭窗口后保留 API 与生成任务。通过托盘／菜单栏查看任务、打开窗口或退出。执行中任务完成后才能正常退出。

数据位置

Chrome 登录资料保存在本机。不要分享包含账号资料的数据目录。

这台电脑

开关读取系统里的真实开机项，只保存在这台电脑。手动打开会显示窗口；开机自启只留在托盘或菜单栏。

WebDAV 同步

同步生成超时、同时执行数，以及账号的邮箱、启用状态和项目编号。端口、调用密钥、代理、浏览器路径和开机自启留在本机。传输走 HTTPS，应用密码放在系统凭据库。同步文件本身没有端到端加密。
