连接 Google 账号

无需安装浏览器插件。使用本机 Chrome，可选择独立登录或已有资料目录。

无需插件

首次使用：在设置中选择浏览器 → 添加账号 → 选择资料模式 → 打开登录窗口 → 同步登录。已有资料需先退出原浏览器；Chrome 默认日常目录可能禁止调试，届时请改用独立登录。EgoLite 暂未适配。旧版 Cookie 同步插件不用于此桌面版。

运行设置

停止 API 后保存，再启动服务使设置生效。

复用本机浏览器，无需插件。已有资料目录需先退出占用它的浏览器。首次登录请到“Google 账号”页面操作。

外部工具接入

使用 OpenAI 兼容协议，填入本机地址和 API Key。

http://127.0.0.1:8000/v1

后台运行

关闭窗口后保留 API 与生成任务。通过托盘／菜单栏查看任务、打开窗口或退出。执行中任务完成后才能正常退出。
