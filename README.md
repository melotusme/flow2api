# Flow2API

本机桌面应用。关闭窗口后留在 macOS 菜单栏或 Windows 通知区域，创作工作台和本机 API 继续运行。

- 使用说明：[docs/desktop-quickstart.md](docs/desktop-quickstart.md)
- 开发、安装与发布：[desktop/README.md](desktop/README.md)
- 浏览器连接：[docs/browser-connection.md](docs/browser-connection.md)
- 接口差异：[docs/desktop-api-compatibility.md](docs/desktop-api-compatibility.md)

默认监听 `127.0.0.1:8000`。外部工具使用桌面应用里显示的 Base URL 和 API Key。
